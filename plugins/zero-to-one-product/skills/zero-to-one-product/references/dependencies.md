# External Dependencies

The plugin bundles only the `zero-to-one-product` router. The phase skills below remain external, independently installed dependencies under their upstream MIT licenses. After installing or updating a dependency, re-check that its exact skill name is available and its selected `SKILL.md` is readable. Restart Codex or open a new session if the current skill catalog has not refreshed.

Use the router explicitly as `$zero-to-one-product <product idea or current 0-to-1 goal>`.
